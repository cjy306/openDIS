# 第一阶段：析出相总含量试跑

四组均无孪晶阻挡面，不预弛豫，使用相同216个125 nm FR源、300 nm周期盒、全盒初始密度1e15 m^-2及[112]加载。应变率1e3/s，终点0.1%（0.0001），构型每1000步输出。用于比较速度，不用于提取屈服。

| 目录 | 原实验含量倍数 | 小颗粒数 | 大颗粒数 | 实际总体积分数 |
|---|---:|---:|---:|---:|
| f000 | 0 | 0 | 0 | 0 |
| f005 | 0.05 | 76 | 6 | 0.0765463% |
| f010 | 0.10 | 152 | 13 | 0.1629604% |
| f020 | 0.20 | 304 | 25 | 0.3160529% |

直径仍为4.9/17.2 nm，小粒90度脱钉、大粒球面绕过。数量取整使实际含量和配比略偏离目标，metadata.json记录实际体积分数。所有组从相同20%含量候选分布取嵌套子集，跨类型不重叠，位错构型相同。

为后续A/B配对，各组颗粒中心均避开z=60/240 nm平面的2R区域。这是人为设置的界面邻近无颗粒区域，不代表已测得实验分布；本阶段没有加载孪晶面。此前原含量A未必采用同样避让，因此只作为运行参考。

将整个目录放到集群$HOME/openDIS下，在各子目录执行：

```bash
sbatch submit_test_sd.sh
```

结束后可执行sbatch submit_vtk_sd.sh；python plot.py绘图。输入和VTK分别保存大小颗粒。f000两个颗粒数组为空，是有效的无颗粒基准。保留原CuNiSi_AB及其结果。

比较相同应变下的累计耗时、dt、节点数与timer.dat各模块耗时；尚未达到共同应变时不要仅比较作业总运行时间。原生GPU运行尚待集群验证。

后续依次进行：选定可承受总含量；固定总量扫描小颗粒体积占比0/约22/50/75/100%；选候选配比做A/B对照（先排查B负应力）；提高含量并增加种子验证趋势。后续总含量和正式屈服所需应变范围依据试跑结果确定，不能预先将0.1%末端应力当作屈服。
